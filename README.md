## Зачем нужен «Падежный фильтр»

Языковые модели склонны выдавать гипотезы и домыслы с той же уверенностью, что и проверенные факты. «Падежный фильтр» переводит диалог с ИИ из режима «генерации правдоподобного текста» в строгий протокол учёта записей:

* **Отделяет факт от гипотезы:** проверяет наличие каркаса Ω(T), оплаченного акта, позиции σ(O) и датированного окна сверки.
* **Запрещает голословные оценки:** ИИ не имеет права использовать слова *«подтверждено»*, *«доказано»*, *«истина»* — только строгие статусы протокола (`легальная запись`, `[Р] кандидат`, `левый край`, `клетка 1`, `снято ложное`).
* **Легализует отказ от ответа:** если данных для внешней сверки нет, нейросеть обязана присвоить статус `неопознанный остаток`, а не фантазировать.
* **Разделяет роли:** ИИ выступает только носителем-исполнителем, а финальную сверку по времени («держать ключ») проводит человек.

## Быстрый старт (за 30 секунд)

1. Откройте файл [`case-filter-v1.2.md`](./case-filter-v1.2.md) и скопируйте его содержимое целиком.
2. Вставьте текст в начало нового диалога с любой современной языковой моделью (ChatGPT, Claude, Gemini, DeepSeek и др.).
3. Подайте любую запись для проверки командой:
   ```text
   ПРОГОН: [ваше утверждение, новость или гипотеза]
   ```

### Основные команды протокола
* `ПРОГОН: [текст]` — разбор записи по карточке с пояснением.
* `СВЕРКА: [Ê против факта E]` — фиксация результата по датированному окну.
* `СВОДКА` — отчёт по дисциплине фильтра и ошибкам О1–О3 за сессию.
* `ПРОГНОЗ: [Ê] окно [дата]` — регистрация кандидата до сверки.
* `АБЛЯЦИЯ: [клетка]` — проверка устойчивости фильтра при исключении выбранной клетки.
